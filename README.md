## 📍 Approach

A few things I care about when building software:

- **Own your infrastructure.** Cloud platforms are convenient until they're not. Running your own stack keeps costs predictable and data where it belongs.
- **Ship one thing properly** before starting the next. AWN will have six modules eventually. Right now it has one, and that one will be bulletproof before anything else is touched.
- **Security is not a feature.** Especially in hospitality software — compliance logs, employee NI numbers, payroll data. These need to be treated correctly from day one.
- **Lightweight by default.** PicoCSS over Tailwind. SWR over TanStack Query. SSE over WebSockets until WebSockets are actually needed.
